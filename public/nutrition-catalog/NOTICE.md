# Атрибуция каталога продуктов

## Товарные позиции (`sku`)

Этот слой собран из открытого экспорта [Open Food Facts](https://world.openfoodfacts.org/)
и распространяется с сохранением атрибуции и условий лицензии
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Для каждой позиции в `foods.full.json` и `provenance.json` сохранены исходная
ссылка, GTIN, дата получения и ссылка на подтверждающую запись.

## Обычные продукты (`reference`)

Этот слой собран из USDA FoodData Central, SR Legacy. Данные USDA находятся
в общественном достоянии (CC0). Для каждой позиции сохранены FDC ID и ссылка
на исходную запись.

Фото не является условием включения позиции: обязательны источник, КБЖУ на
100 г и данные для проверки записи.
