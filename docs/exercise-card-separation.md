## Модель

`trainerExerciseCards/{id}` — приватные карточки владельца. Запись только через авторизованный серверный API, клиентский прямой доступ закрыт.

Упражнение программы хранит `exerciseCardId`, `exerciseCardOwnerUid`, снимок метаданных `exerciseCardSnapshot`, отдельные исключения `exerciseCardOverrides` и собственную нагрузку. Снимок обеспечивает доступность без сети и позволяет отличить локальную правку от общей карточки.

Старые упражнения связываются по точному совместимому ключу «нормализованное название + видео + техника». Подходы, веса и отдых не участвуют в сопоставлении. При первом сохранении библиотечного упражнения создаётся отдельная карточка с постоянным ID и исходным ключом. Перенос ленивый и идемпотентный: существующие шаблоны, назначения и история не перезаписываются. Новые назначения получают явную ссылку при чтении актуального шаблона.

Разные видео/инструкции сохраняются как отдельные карточки; неоднозначные совпадения не связываются. Удаление скрывает карточку из выбора, но не удаляет её из программ и истории. Общая административная база базовых тренировок остаётся отдельной.

Метаданные подставляются при загрузке/обновлении программы, не посреди открытого подхода. Старые пустые или автоматически унаследованные видео получают актуальную карточку через существующее сопоставление с шаблоном. Собственное отличающееся видео старой копии без ссылки не считается доказанной общей карточкой: оно сохраняется, автоматического принудительного объединения нет. Для нового связанного упражнения локальная правка относительно `exerciseCardSnapshot` становится исключением.

Предыдущие названия и каталожные идентификаторы сохраняются для поиска старой истории и иллюстраций. Ссылки также проходят через добавление упражнения, выбор альтернативы, назначение и сохранение клиентской программы. Нагрузки альтернатив не копируются в рабочий слот.
