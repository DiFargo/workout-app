Объединяются только точные проверенные варианты названий, например «Приседания с гантелью» / «Присед с гантелью», «Жим гантелей лёжа» / «Жим лёжа с гантелями». Отличия хвата, наклона, положения тела и оборудования сохраняются. Похожие, но неоднозначные названия автоматически не объединяются.

## Реализация

`functions/exerciseLibraryIdentity.js` — чистый общий модуль идентичности: Vite включает его в клиентскую сборку, Firebase публикует вместе с функцией поиска видео. Клиентская библиотека и сервер используют один словарь. Исключение явно включено в проверку графа модулей.

`src/utils/trainerExerciseLibrary.js` строит представление без записи в базу; его же использует редактор вместо второго самостоятельного алгоритма дедупликации. `src/utils/trainerLibraryMuscleGroups.js` исправляет классификацию без изменения подбора анатомических иллюстраций базовой программы.
