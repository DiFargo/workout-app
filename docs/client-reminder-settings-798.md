## Контракт

`telegramUpdateNotifications` сохраняет прежний запрос `{ enabled: boolean }` и принимает отдельный `{ reminderSettings }`. Сервер проверяет полный ограниченный набор полей. В Firestore выполняется вложенный merge только параметров напоминаний, без перезаписи расписания, ролей или идентификаторов Telegram. Начало существующего цикла фото/замеров не сбрасывается при редактировании.

`telegramTestWorkoutReminder` разрешает текущему пользователю отправить тест себе; чужой `clientId` требует прежней проверки назначенного тренера/администратора. Ограничение частоты сохранено.

В `telegramDailyWorkoutReminders` условие отключённого тренировочного календаря ограничивает только тренировочные сообщения. Общий отказ от Telegram проверяется до всех категорий.

Структура интерфейса следует ui-ux-pro-max: отдельные карточки, дополнительные параметры раскрываются только для включённой категории, подписи и состояния доступны скринридеру, кнопки не меньше 44 px. Поиск в справочнике по progressive disclosure не дал подходящего результата; использованы общие правила Quick Reference выбранного навыка и существующие компоненты проекта.
