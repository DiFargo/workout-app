# Назначение программы: индивидуальное название — 3.0.758

## Причина

`assignSavedProgramToClient` создаёт клиентскую копию с автоматически составленным или введённым тренером названием (до 80 символов). `isTrainerProgramAssignmentFields` требовала точное совпадение этого названия с именем библиотечного шаблона. Атомарная запись отклонялась с `permission-denied`, даже когда тренер владел шаблоном и клиент был назначен ему.

## Исправление и критерии

- [x] Разрешено отдельное непустое строковое название клиентской копии длиной до 80 символов.
- [x] Сохранены проверка владельца шаблона, текущего назначенного тренера и разрешённых полей профиля.
- [x] Назначение 12 тренировок с автоматическим и ручным названием проходит атомарно; имя шаблона, предыдущие тренировки и история не меняются.
- [x] Чужой тренер, чужой шаблон, отозванный доступ, неверное название и смена роли отклоняются без частичного сохранения.
- [x] До исправления новый сценарий воспроизводил отказ; после исправления прошли все 46 тестов Firestore Rules и 43 профильных unit-теста.
- [x] ESLint выбранного тестового файла и `git diff --check` проходят.
- [x] Сборка и публикация Hosting + Firestore Rules.
- [x] Проверка опубликованной версии без назначения программы на данных пользователя.

Публикация исправления отдельно подтверждена пользователем. Изменения серверных Functions и Storage Rules не требуются.
