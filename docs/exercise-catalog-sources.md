# База упражнений для базовых планов

## Полный справочник

`src/data/basicWorkoutFullExerciseCatalogue.generated.js` содержит 873 записей
Free Exercise DB. Источник выпущен под Unlicense/public domain:

- репозиторий: <https://github.com/yuhonas/free-exercise-db>
- экспорт: <https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/dist/exercises.json>
- лицензия: <https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md>

В приложение импортируются только фактические поля: стабильный идентификатор,
каноническое исходное название, категория, уровень, инвентарь и мышцы. Исходные
пошаговые инструкции и пути к изображениям не сохраняются. Русское описание,
подсказка по технике и предупреждение о безопасности создаются нашим импортёром
из структурных полей и являются оригинальным текстом приложения.

Неясные и узкоспециализированные названия честно остаются с исходным английским
каноническим названием (`titleStatus: "source-fallback"`), а русскими остаются
категория, группы мышц и описание. Это не выдаёт машинный или неточный перевод
за проверенное русское название. Проверенные русские названия маркируются
`titleStatus: "verified"`.

Полный каталог публикуется как версионированный статический файл
`/basic-workout/exercise-catalogue.v1.json` и загружается лениво через
`src/data/basicWorkoutFullExerciseCatalogue.js`, поэтому не увеличивает
начальную загрузку приложения.

## Набор для ИИ-планов

ИИ не использует весь справочник автоматически. Только проверенный набор из
клиентской библиотеки попадает в `functions/basicWorkoutAiCatalogue.generated.js`.
Он содержит канонические русские названия, алиасы, оборудование, отдых и роль
движения. Это исключает непроверенные, олимпийские, силовые, плиометрические и
другие сложные варианты из базовых планов.

Обновить артефакты после проверки нового исходного файла:

```powershell
node scripts/import-free-exercise-catalog.mjs --input <путь-к-exercises.json> --public-out public/basic-workout/exercise-catalogue.v1.json
node scripts/build-basic-workout-ai-catalogue.mjs
```

Перед импортом нового источника необходимо проверить лицензию, точное число
записей и не добавлять в приложение сторонние тексты или изображения без
отдельного разрешения.
