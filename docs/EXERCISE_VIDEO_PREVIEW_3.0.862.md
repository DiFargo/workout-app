# Превью упражнения — 3.0.862

Пользователь попросил добавить тренеру выбор понятного кадра в редакторе упражнения, чтобы клиент видел положение тела до запуска видео. После проверки разрешена немедленная публикация в Production.

## Единая приёмка

- [x] В редакторе упражнения рядом с кадрированием доступен выбор превью из ролика.
- [x] Выбранный кадр использует существующее квадратное кадрирование, виден без автозапуска; Play начинает демонстрацию с начала, обычная пауза/продолжение не перематывают её.
- [x] Выбор меняет только черновик; «Отмена» сохраняет прежний выбор, а сохранение упражнения сохраняет превью.
- [x] Превью проходит через общую карточку, назначенную программу, клиентское обогащение и альтернативы; замена видео сбрасывает старый кадр.
- [x] Нагрузка, завершённая история, роли, доступы, навигация и таймер не изменены.
- [x] Профильные тесты, локальная Firestore-транзакция, mobile/browser и сборки пройдены.
- [x] Живой staging подтверждён, собственные временные данные удалены с проверкой.
- [x] Production опубликован минимальным набором целей и проверен read-only.
- [x] Завершено 30-минутное read-only наблюдение с ограничениями данных.
- [x] Пользователь подтвердил поведение в настоящем Telegram.

## Реализация и границы

Хранится только `videoPosterTime`: конечное число 0…86400 секунд с точностью до миллисекунд либо `null`. Отдельные изображения, публичные Storage-ссылки и перекодирование не создаются. Защищённый плеер загружает выбранный момент в паузе; первое воспроизведение начинается с нуля. Предпросмотр требует загрузки соответствующего фрагмента видео, это не отдельная офлайн-картинка.

Настройка доступна в редакторе тренерской карточки упражнения. Общая административная базовая библиотека не получает новый отдельный редактор. Полноэкранное видео остаётся исходным. Уже завершённые тренировки и история не переписываются.

`ui-ux-pro-max` повлиял на явный выбор кадра, отсутствие автозапуска, подсказки и доступные действия листа. React-рекомендации использованы для переиспользования существующего видеоплеера без дополнительного изображения или зависимости. `playwright` используется для проверки реального декодирования, выбора и воспроизведения.

Локальный Firestore emulator (`demo-workout-rules`): реальная транзакция сохраняет `videoPosterTime: 1.2`, API выдаёт его клиенту; назначения и история не переписываются, конфликт ревизий и запрет прямого доступа для всех ролей сохранены. Проверка прошла, emulator остановлен.

Chromium с настоящим декодированием fixture-видео: выбор 1,2 секунды, черновик без записи, единственное сохранение карточки, повторное открытие, отмена нового выбора, сохранение crop и сброс при upload — пройдены.
