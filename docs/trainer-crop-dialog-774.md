# Окно кадрирования видео — 3.0.774

В библиотеке упражнений большой закреплённый редактор заменён компактным
предпросмотром и кнопкой «Настроить кадр».

## Поведение

- Отдельное стандартное окно: кадр 4:3 или весь ролик без обрезки.
- Перемещение видео мышью, пальцем, стрелками клавиатуры или отдельными кнопками.
- Один ползунок масштаба, воспроизведение, перемотка и сброс.
- «Отмена», крестик и Escape закрывают окно без изменения черновика упражнения.
- «Применить» обновляет только черновик. Запись общей карточки происходит при
  последующем нажатии «Сохранить» в редакторе упражнения.
- Полноэкранное видео остаётся исходным. Нагрузка, шаблоны программ и история
  не изменяются.

Использован существующий `TrainerEditorSheet` (нативный dialog в верхнем слое).
Он остаётся внутри DOM редактора: это сохраняет совместимость с его блокировкой
фоновой прокрутки. Прокручивается тело окна; заголовок и действия не скрываются.

## Проверка

- Основной мобильный размер: 402 × 874; дополнительно 320 × 720, 1366 × 768
  и альбомный 874 × 402.
- Проверены загрузка, кадрирование, воспроизведение, перемотка, сохранение,
  отмена, Escape, крестик и отсутствие изменения программы.
- Отдельно проверены реальные touch-события Chromium, прокрутка короткого окна
  402 × 520, неподвижность фонового редактора и закрытие касанием.
- WebKit: геометрия 4:3, ошибка загрузки, повтор и закрытие. Воспроизведение H.264
  в Windows WebKit не поддерживается средой тестирования; проверка настоящего
  Safari на устройстве этим тестом не заменяется.

Изменения ограничены клиентским редактором, стилями и его тестами. Публикация —
только Firebase Hosting; правила доступа и серверные функции не изменяются.
