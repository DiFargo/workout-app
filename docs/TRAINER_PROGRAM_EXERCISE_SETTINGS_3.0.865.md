# Настройки упражнений в программах — 3.0.865

## Согласованный результат

В настройках упражнения клиентской программы и общего шаблона видео имеет
квадратную область просмотра. Заменять файл в этих окнах нельзя: видео
редактируется в библиотеке упражнений. Удаление явно относится только к
текущей тренировке. В подтверждении удаления крестик доступен по всей своей
видимой области.

## Границы изменений

Меняются только UI редакторов программ и слой кнопки закрытия подтверждения.
Библиотечные обработчики, Firebase, Storage Rules, права доступа, история,
выполнение тренировок и таймеры не меняются.

Квадрат ограничен шириной 320 px и шириной доступного окна; исходный ролик
отображается целиком через `object-fit: contain`. Содержимое настроек при
необходимости прокручивается, поэтому квадрат не вытесняет элементы управления
за пределы доступной области без возможности добраться до них.
