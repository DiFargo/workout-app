# Поиск по базе и дополнительный поиск Gemini

С версии 3.0.779 основной текстовый поиск работает при вводе по каталогу из 10 000 карточек. JSON и индекс обрабатывает `personalNutritionCatalog.worker.js`, каталог сохраняется на устройстве. Gemini вызывается отдельно кнопкой «Поискать через Gemini». Вкладка «Моя база», дневник, поиск по фото, голос и ингредиенты сохраняют свои существующие пути.

Состав нового каталога, ограничения единиц КБЖУ и источников: [README каталога](../output/belarus-products-10000/README.md). Запись Gemini с неизвестной единицей предлагает уточнить исходную массу/объём перед выбором порции. Это подтверждение пользователя, а не независимая проверка этикетки.

- Переключатель: [nutritionSearchMode.js](../src/utils/nutritionSearchMode.js), `GEMINI_ONLY_FOOD_SEARCH=false`. Экспериментальный режим только Gemini выключен.
- Сервер: [geminiNutritionSearch.js](../functions/geminiNutritionSearch.js), вызывается через авторизованный `GET /api/nutrition/search?provider=gemini&q=...`.
- Ключ: секрет Firebase `GEMINI_API_KEY`, привязан только к функции `nutritionSearch`. Клиент ключ не получает.
- Один поиск делает два вызова модели: веб-поиск и извлечение карточек из найденного текста. Лимиты существующего API: 40 запросов в минуту и 300 в сутки на пользователя. Автоматического повтора и подмены другим провайдером нет.
- Карточки отмечены как требующие проверки. Наличие ссылки не гарантирует правильность распознавания; сверяйте бренд, разновидность и значения с источником. Неизвестные значения не заменяются нулями, данные на 100 мл не выдаются за 100 г.
- Ссылки берутся из метаданных Google. Поисковые подсказки Google отображаются в изолированном iframe без доступа к приложению и выполнения скриптов.

Реальный API проверен на Nutella и «Творог Савушкин 5%». UI-тест использует ответы-заглушки для стабильной проверки кнопки, отсутствия каталога, источников, выбора карточки, ошибки и повтора.

## Публикация

Выпуск 3.0.779 меняет только клиент и статический каталог; достаточно Hosting. Functions и правила Firebase не меняются. Проверять версию, опубликованный worker, JSON каталога, экран входа и защиту API; добавление и сохранение проверять в изолированном тестовом окружении.
