## Безопасное применение

Существующие карточки получают только время кадра и необходимые поля конкурентного редактирования. Приоритет прежнего видео сохраняется. Базовый каталог получает только `videoPosterTime`.

Два старых упражнения переводятся в общие карточки штатной логикой `manageTrainerExerciseCards`; состав исходных шаблонов не меняется. Создание защищено `exists=false`, а исходные шаблоны — атомарной проверкой версии. Дата создания карточки не должна делать старое видео новее.

Все записи выполняются одним `documents:commit` с предусловиями. Перед операцией сохраняется намерение, после успешного ответа — квитанция, затем выполняется повторное чтение. При неоднозначном сетевом сбое запрещён слепой повтор: сначала сверка с намерением и состоянием библиотеки.

Не меняются видеофайлы, кадрирование, подходы, веса, повторы, отдых, роли, авторизация, навигация, история и назначенные программы. Rules, Functions, IAM и платные сервисы не перенастраиваются.
