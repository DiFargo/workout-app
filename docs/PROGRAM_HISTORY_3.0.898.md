# История программ и удаление пустого архива — 3.0.898

## Результат

- Реализован выбранный вариант «Текущая и архив»: текущая программа отдельно сверху, остальные назначения — от новых к старым.
- Одновременно раскрывается одно назначение. Просмотр показывает сохранённые тренировки, состав и подходы, не меняя программу.
- Возврат из архива явно сохраняет прежние отметки и даты, не создаёт новое прохождение и не заменяет другую текущую программу.
- У старых пустых архивных назначений есть отдельное удаление с подтверждением. Общий шаблон, остальные назначения, питание, абонемент и история не удаляются.

## Границы удаления

Новая операция `/api/trainer-program-assignment-delete` принимает только `clientId` и точный `assignmentKey`. Сервер внутри транзакции перечитывает роли, связь тренера с клиентом, документы тренировок и историю. Архив должен быть однозначным и не являться текущим или самостоятельным базовым планом. Любая связанная история, пропуск, завершение, начало, фактические значения или другие признаки выполнения блокируют удаление. Превышение лимита проверки также означает отказ без частичного удаления.

Из календаря убираются только точные ссылки на удаляемые дни; чужие даты сохраняются. Клиент обновляет локальную копию только по подтверждённым сервером ID и только в том же сеансе и карточке клиента. Существующая отдельная административная операция управления назначениями сохранена; новое действие истории всегда использует строгую проверку пустого архива.

Сервер не видит неотправленные offline-черновики на другом устройстве. Подтверждение напоминает дождаться синхронизации, если клиент занимался без интернета. Отсутствие серверной истории не называется доказательством того, что тренировка никогда не начиналась.
