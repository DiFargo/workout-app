## Границы пакета

Автопереход к следующему подходу после истечения отдыха остался идеей на
обсуждение и не включён. Существующие таймер, ручной переход и динамичная
кнопка сохранены. Авторизация, роли, правила Firebase, Cloud Functions,
питание, замеры и данные реальных клиентов не изменяются.

Черновик локален для аккаунта и устройства. Этот пакет не добавляет облачную
синхронизацию незавершённой тренировки между разными устройствами.

Публикация после проверки явно разрешена пользователем 24 октября 2026 года.

## Исправленные причины

1. Проверка общего marker версии раньше удаляла все черновики аккаунта при
   отсутствии или смене marker, включая актуальное назначение и basic-режим.
   Теперь проверяется назначение конкретной тренировки.
2. В черновике сохранялась вся программа с дублирующими `_editorSnapshot`.
   Теперь сохраняется только активная тренировка, без редакторского snapshot;
   при отказе записи показывается предупреждение. Восстановление возвращает
   фактические упражнения только активной тренировки в актуальный план.
3. Итог после сохранения пересчитывался по обновлённому серверному плану без
   runtime-отметок. Теперь берётся сохранённая история точной текущей сессии.
