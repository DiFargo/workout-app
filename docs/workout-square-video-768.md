- [x] Видео занимает всю ширину блока упражнения и имеет квадратное соотношение сторон 1:1.
- [x] Исходное видео показывается целиком (`object-fit: contain`), без обрезки техники движения.
- [x] Воспроизведение/пауза и разворот оформлены круглыми полупрозрачными кнопками: белые значки, размытие 12 px, мягкий блик и светлый край.

- [x] Предусмотрены уменьшение движения, уменьшение прозрачности и подложка для браузеров без размытия.
- [x] Подходы и информация под ними доступны прокруткой над закреплённой нижней панелью, включая маленькие экраны и safe area.

Изменения ограничены CSS Modules видеоблока и его контейнеров, декоративным `aria-hidden` у значка и тестовым harness. Навыки UI/UX и полировки интерфейса использованы для локального стеклянного эффекта, контраста, размеров нажатия и короткого отклика без hover-эффектов на touch.
