## Поведение

В последнем шаге опроса появился подписанный системный список «Акцент программы».
Существующая схема сохранена как «По группам мышц» и остаётся значением по умолчанию
для старых/пустых ответов. Пользователь сам выбирает новый вариант; пол не выбирает его автоматически.
Новый экран и обязательный шаг не добавлены. Выбор доступен для изменения на проверке ответов.

Для трёх занятий:

| Вариант | Неделя |
| --- | --- |
| По группам мышц | Ноги → жимовой верх → тяговой верх, без изменений |
| Сбалансированно | Три варианта тренировки всего тела |
| Ноги и ягодицы | Низ А → верх → низ Б |
| Верх тела | Верх А → ноги и всё тело → верх Б |

Также заданы отдельные последовательности для 2, 4 и 5 занятий. Акцент перераспределяет
слоты и подходы, не увеличивая суммарное число упражнений и подходов между новыми вариантами
при одинаковых остальных ответах. Начинающий/щадящий режим продолжает ограничивать подходы.
В 30-минутных новых вариантах три слота используются под основные движения; отдельный кор
не обязателен в каждой тренировке. В длинных вариантах кор завершает занятие.

В результате показаны подходы за первую неделю для низа, верха и кора. Это учёт по основной
роли движения, а не точная оценка нагрузки на каждую мышцу; косвенная нагрузка не дублируется.
Объём и предпочтения не являются медицинской рекомендацией и не гарантируют оптимальность:
существующие ограничения автоматического подбора и необходимость тренера при особых состояниях сохранены.

## Контракт и границы

- `trainingEmphasis`: `classic | balanced | lower | upper`. Неизвестное/отсутствующее → `classic`.
- `functions/basicWorkoutEmphasis.js` — единые значения, шаблоны и подсчёт объёма.
- Сервер нормализует поле; Gemini получает уже сформированные слоты нужного акцента и не меняет их роли.
- Локальный резервный подбор использует те же шаблоны и проверки, явно отмечается как подбор без Gemini.
- Если старый сервер не вернул выбранный акцент, клиент не принимает такой план молча.
- `weeklySetDistribution` формируется из фактических подходов результата, не из текста ИИ.
- Рабочие веса остаются ручными. Сохранённые программы, история и нагрузки не мигрируются.
- Режим «На сегодня» сохраняет свой независимый выбор зон. Новое поле на него не влияет.
- Firebase auth, права, тарифы, лимиты, правила и календарная логика не менялись.
