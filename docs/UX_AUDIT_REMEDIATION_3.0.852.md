# Доработки по UX аудиту: 3.0.852 и завершающая 3.0.853

Дата: 19 октября 2026 года. **Завершающая Production 3.0.853 опубликована; подтверждение завершения — 09:54:01 UTC (12:54:01 Минск).** Предшествующая 3.0.852 опубликована в 09:23:36 UTC.

Узкая поправка 3.0.853 устраняет вложенную кнопку повтора в кнопке тренерской миниатюры: повтор остаётся в отдельном просмотрщике. Ошибка декодирования больше не подменяет компонент постоянной заглушкой. Новые DOM-проверки покрывают ошибки сети и декодирования, открытие просмотрщика, успешный повтор и очистку после выхода. Авторизация, роли, Firebase-правила и приватные URL этим дополнением не менялись.

Реализованы изменения для всех 38 пунктов [UX аудита](UX_VISUAL_PERFORMANCE_AUDIT_2026-10-19.md): ясность состояний и действий, сохранение контекста, мобильная компоновка и облегчение запуска. Опубликован только Hosting проекта `tren-85720`; Functions, Rules и IAM этим выпуском не изменялись. Живые проверки трёх ролей и приватных фото прошли на staging и Production; отдельно прошла защита видеопотока Production. Ограничения реальных устройств и наблюдения приведены ниже.

Рабочая база — `394a5849` с сохранением существующих незакоммиченных изменений. Массового отката к старым файлам не выполнялось. Правки сохраняют ролевые проверки, назначение тренера, историю, защищённые медиа и существующие пути изображений замеров.
