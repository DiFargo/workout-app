## Объём и проверки

Переход использует существующие `getWorkoutPrimaryAction` и `handlePrimaryAction`, включая 400-мс защиту, выбор следующего подхода, групповую последовательность и остановку отдыха. Ни один подход из окна отдыха не отмечается выполненным. Не меняются Firebase, история, роли, сохранение тренировки, питание, кабинет или навигация других модулей.

`ui-ux-pro-max` используется для различия главного перехода и вторичного сворачивания, сохранения существующего градиента и доступных целей нажатия. React-рекомендации — для переиспользования текущего обработчика без параллельной модели состояния; `playwright` — для проверки настоящих нажатий и мобильного размещения.

30 профильных unit-проверок прошли: последовательность, timed-гонки, модель динамичной кнопки, countdown, трисет и защитные ограничения smoke-verifier. Scoped ESLint для runtime, smoke-скрипта и двух изменённых browser-spec и `git diff --check` прошли. Полный набор приложения, Rules/Functions и зависимости повторно не проверялись, поскольку они не менялись; объём выбран по `AGENTS.md`.
