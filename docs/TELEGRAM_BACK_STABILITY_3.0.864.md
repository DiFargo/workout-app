# Стабильная кнопка «Назад» в Telegram — 3.0.864

## Задача и причина

Убрать мерцание системной кнопки Telegram в разделе тренировок, сохранив
навигацию, приоритет открытых окон и работу таймеров.

В `useAppBackNavigation` эффект зависел от обработчика, который `AppCore`
создаёт заново при рендере. Обновление таймера активной тренировки происходило
каждую секунду: очистка эффекта скрывала кнопку, а новая подписка показывала
её снова. Повторное событие готовности SDK также пересоздавало подписку.

Исправление ограничено жизненным циклом кнопки Telegram. Обработчик использует
актуальное состояние через ссылку; подписка и видимость не пересоздаются при
неизменном требуемом состоянии кнопки. Повторная готовность того же SDK не
дублирует обработчики. Бизнес-логика, таймеры и оформление не меняются.

Браузерные проверки воспроизводят Telegram BackButton через контролируемый

проверку системной кнопки в настоящем приложении Telegram. Реальные клиентские
данные и история тренировок для проверки не изменяются.
