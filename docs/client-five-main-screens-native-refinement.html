Палитра: системный светло-серый фон, белые поверхности, чистый синий для действий и мягкие оттенки статусов. Цвета адаптированы для спокойного веб-интерфейса; это не автоматические UIKit-цвета.

Это отдельный прототип для согласования дизайна. Данные демонстрационные; изменения сохраняются только до обновления макета. Внешние сервисы, камера и запись голоса не подключены. Системное время, индикаторы батареи и имитация выреза экрана не добавлены.
