# Компактная шапка тренировки — 3.0.769

## Критерии приёмки

- [x] Название упражнения по центру, счётчик непосредственно под названием; светлое оформление текущего приложения.
- [x] Компактный системный шрифт 17 px, перенос длинных названий без обрезки; высота строки масштабируется со шрифтом.
- [x] Во время активной тренировки только один верхний выход — крестик. Нижняя кнопка предыдущего упражнения сохранена.
- [x] В режиме просмотра сохранённой тренировки остаётся предусмотренная стрелка возврата, без второго крестика.
- [x] Существующие `onExit` / `onBack` и запрет нажатия при сохранении не изменены. Незавершённая тренировка по-прежнему требует подтверждения выхода.
- [x] Квадратное видео, стеклянные кнопки, таймер и прокрутка до последних подходов сохранены.

Причина дублирования: в `WorkoutRunTopControls` стрелка всегда отображалась и при `showBackButton=false` вызывала тот же `onExit`, что и крестик. Теперь эти элементы выводятся взаимоисключающе. Логика сохранения, черновиков, назначения нагрузки, Firebase и история не изменялись.

Навыки UI/UX и полировки интерфейса применены для компактной иерархии заголовка, симметричных отступов и сохранения зоны нажатия 44 × 44 px.

## Проверки

- Шесть профильных UI-проверок прошли: шапка в мобильном/настольном Chromium; существующие overlays и полный цикл тренировки; прокрутка в WebKit и touch/safe-area Chromium. Два пропуска дублирующих конфигураций предусмотрены тестами.
- Геометрия шапки: 320, 393, 427 и 812 px, в том числе landscape. Длинное название с увеличением шрифта до 24 px не обрезается. Крестик вызывает переданный обработчик выхода; сохранённый режим использует отдельный возврат.
- Прямая проверка `requestLeaveWorkout` подтверждает вызов существующего запроса подтверждения для активной несохранённой тренировки.
- Профильный ESLint, `npm run verify` и `git diff --check` прошли. Начальный gzip JS — 61.61 KiB при лимите 100 KiB; прежнее предупреждение о крупном App-чанке сохраняется.
- Скриншот мобильной шапки просмотрен.
