# Автоматический отдых и градиент кнопки — 3.0.858

Пользователь уточнил, что после «Подход выполнен» нужно автоматически показывать большое окно отдыха, как раньше, а основная кнопка должна иметь существующую градиентную заливку приложения. Публикация после проверки разрешена отдельно.

## Единая приёмка

- [x] После корректного выполнения подхода окно отдыха открывается автоматически; выбранный подход остаётся прежним.
- [x] Сворачивание и окончание отдыха не выполняют следующий подход. Для перехода сохраняется отдельное нажатие.
- [x] Отмена и пропуск отдыха сохраняют корректное состояние, поздний timed-callback не снимает отметку.
- [x] В суперсете/трисете отдых открывается только после последнего упражнения круга.
- [x] Основная кнопка использует общий `--ownset-action-gradient`, не отдельный новый градиент.
- [x] Без открытого окна видео, подход, отдых и нижняя кнопка остаются видимыми на мобильном экране; размер видео при выборе подходов стабилен.
- [x] Профильные проверки, сборка и read-only сверка опубликованной версии выполнены.
- [x] Завершено 30-минутное read-only наблюдение ошибок и квот после публикации; ограничения `no_data` и задержки метрик зафиксированы ниже.
- [x] Пользователь подтвердил в настоящем Telegram.

## Объём

В runtime изменены только callback раскрытия отдыха в `WorkoutRunStageView.jsx` и заливка в `WorkoutStageActionPanel.module.css`. Сигнал открытия берётся из существующего `toggleWorkoutSetCompleted`: неверная очередь, отмена и промежуточное упражнение группы не запускают отдых. Логика отметки, timed-guard, порядок выполнения, сохранение, Firebase и роли не заменяются. Версия обновлена на 3.0.858.
