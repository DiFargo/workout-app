# Копирование выполненного дня — 3.0.890

## Поведение

- В редакторе индивидуальной программы кнопка «Копировать тренировку» доступна и для выполненных дней на ПК и телефоне.
- Копия добавляется в конец программы и сразу выбирается в редакторе. До нажатия «Сохранить» это только черновик; «Отмена» удаляет несохранённую копию.
- Копия имеет статус `planned`, новые идентификаторы дня, упражнений, подходов и блоков. Результаты прошлого выполнения, заметки клиента, даты старого запуска и старого расписания не переносятся.
- Назначенные повторы, веса, длительность тайм-подходов, отдых, техника, альтернативы, карточки библиотеки, видео, превью и кадрирование сохраняются.
- Выполненный оригинал по-прежнему нельзя изменять, удалять или перемещать. Его документ и история не переписываются при сохранении копии.

- [x] Доступность кнопки копирования выполненного дня на ПК и мобильном экране.

- [x] Отмена не сохраняет копию; явное сохранение и повторное открытие сохраняют её статус.
- [x] Нет горизонтального переполнения на ширине 320 и 402 CSS px.

## Границы изменений

Изменены только клиентские обработчики копирования и доступность существующей кнопки. Firebase Rules, серверные функции, аутентификация и роли не менялись. Проверки записи выполняются на локальных фиктивных данных; реальные программы клиентов не редактировались.

Исходные файлы перед этой правкой сохранены в `artifacts/completed-day-copy-2026-10-29/baseline/`. Это точечная резервная копия текущей базы 3.0.889, а не откат более ранних функций.
