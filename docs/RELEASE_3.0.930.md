# Выпуск 3.0.930

Дата: 8 ноября 2026 года. Цель публикации: только Firebase Hosting проекта `tren-85720`.

## Изменения

- Портальные окна тренера получают резервное значение слоя, даже если переменная рабочего контейнера не наследуется. Вкладки карточки клиента больше не перекрывают окно расписания.
- В клиентском календаре строка месяца и стрелки закреплены при прокрутке содержимого.
- Бизнес-логика, серверные функции, правила доступа и данные пользователей не менялись. Исследовательские макеты не переносились в runtime.

## Проверки

- 12 проверок модели расписания прошли.
- 9 браузерных проверок расписания тренера прошли; одна повторная desktop-проверка адаптивности пропущена самим тестом, который проверяет размеры в mobile-проекте.
- 3 браузерные проверки клиентского календаря прошли, включая доступность стрелок после прокрутки на экране 320 × 568.
- ESLint изменённых тестов, production-сборка Node 22, проверка маркера Firebase-артефакта и проверка пробелов diff прошли.
- Полная проверка всех модулей и live-сценарии с авторизацией не повторялись; реальные пользовательские записи не менялись.
- Публикация Hosting завершена. В Production проверены маркер 3.0.930 в service worker, соответствие index.html сборке и побайтное совпадение обоих исправленных CSS-файлов; оба исправления присутствуют.

## Согласованное исключение

Firebase core: 189,04 KiB gzip при бюджете 170 KiB. Файл `firebase-DQpFvnNL.js` побайтно совпадает с опубликованной 3.0.929. Пользователь разрешил публикацию после сообщения об этом превышении. Лимит не увеличивался, оптимизация Firebase-бандла не входит в данный пакет.
