# Сохранение количества назначенных подходов

Версия 3.0.760, 10 сентября 2026. После отмены случайной просьбы пользователь отдельно подтвердил «после опубликуй». Выпуск опубликован только в Firebase Hosting; сохранённые данные не изменялись.

## Причина

`makeThreeSets` использовала минимум из трёх подходов даже при наличии готового назначения на один или два. Её вызывают загрузчики клиента и тренера через `normalizeExercise`, модель активного упражнения, а также прежние пути сохранения и копирования программы. Замена упражнения сама сохраняет массив подходов, но последующая нормализация добавляла пустые строки.

Проблема воспроизведена тестами до исправления: 1 → 3, 2 → 3, два подхода на время → три. Теперь исходная длина непустого массива сохраняется; три подхода создаются только при отсутствии назначения. Групповые упражнения по-прежнему используют заданное число кругов.

## Критерии готовности

- [x] Готовые назначения на 1, 2, 3 и 5 подходов сохраняют количество и параметры при загрузке, изменении описания/видео и замене упражнения.
- [x] Исходный шаблон не мутируется; независимые параметры подходов сохраняются.
- [x] Реальный клиентский загрузчик проверен с настоящей нормализацией после обновления библиотечного видео, а не с прежней заглушкой.
- [x] Назначения на время и заданные круги трисета не получают лишних подходов.
- [x] 41 профильный тест, production build, ESLint изменённого модуля и тестов, `git diff --check` — успешно. Существующее предупреждение о размере JS-чанка осталось.
- [x] Публикация выполнена после явного подтверждения; программы пользователей и история не переписывались.

## Ограничение восстановления данных

Это предотвращение повторного автодобавления, не миграция уже сохранённых программ. По одному пустому весу невозможно безопасно отличить лишний подход от намеренно заданного тренером. Если лишние строки уже сохранены в облаке, для восстановления необходимы конкретная программа и исходное назначение/резервная копия; автоматическое удаление не выполняется.

Версия также содержит подготовленное ранее уплотнение блока подходов и уменьшение названия упражнения из 3.0.759.
