## Границы

Изменяется представление `LoginPage`; Firebase handlers, серверные функции, Rules, IAM, роли, история, навигация авторизованных пользователей и привязка Telegram не меняются. В браузере сразу показана форма пароля, при приглашении или уже доступном Mini App SDK — Telegram. Поздний SDK не переключает самостоятельно уже выбранный пользователем способ входа.

Стилями нового компактного экрана владеет colocated `CompactAuth.module.css`; старые общие login-правила не переиспользуются, чтобы не переносить их каскад в утверждённую геометрию. Splash остаётся прежним.

Восстановление поддерживает и email, и логин существующим обработчиком. Кнопка «Забыли пароль?» открывает форму и сама не отправляет письмо. Для регистрации видна информация об ознакомительном доступе до назначения тренера; конфиденциальность доступна перед отправкой формы.

`ui-ux-pro-max` использован для компактной группировки, постоянных подписей полей и контекстных пояснений. `firebase-auth-basics` — для сохранения действующих auth-контрактов; его общая рекомендация Google не применяется, поскольку пользователь явно попросил временно убрать этот способ из интерфейса. React-рекомендации использованы без новых зависимостей и переработки состояния приложения.
