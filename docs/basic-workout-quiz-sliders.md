# Подбор программы: интерактивный макет

Основной экран устройства: iPhone 17 Pro, 402 × 874 CSS px.

Открытие: `python -m http.server 4191 --bind 127.0.0.1 --directory docs`, затем [локальный макет](http://127.0.0.1:4191/basic-workout-quiz-sliders.html).

## Решения

- Цель: 4 фиксированные остановки; опыт: 3; место: 2; частота: 1–5; время: 30/45/60/90 минут.
- Ползунки управляются перетаскиванием, клавиатурой и нажатием подписей. Выбранный ответ имеет полный заголовок и краткое объяснение.
- Ограничения остаются списком вариантов. Для «Другое» требуется пояснение.
- Пожелания: четыре варианта акцента и необязательный комментарий. Дополнительное распределение показано только для двух тренировок по группам мышц.
- Проверка: короткая сводка с переходом к редактированию отдельного ответа. Данные профиля и пояснения раскрываются по запросу.
- Девятый экран — только пример обзора, без сгенерированных упражнений.

## Границы

Это самостоятельный макет. Приложение, Firebase, данные пользователей и версия релиза не менялись. Вызовов Gemini, отправки сообщений и сохранения программы нет. Профиль явно помечен демонстрационным.

При внедрении варианта «1 раз в неделю» нужно отдельно обновить и проверить ограничения клиентского черновика, серверного генератора и структуры программы: текущая рабочая модель допускает 2–5 дней. Макет сам по себе эту поддержку не добавляет.

## Проверка

`node --check docs/basic-workout-quiz-sliders.js`

`node artifacts/check-basic-quiz-sliders-mockup.mjs`

Проверены девять экранов в Chromium (402 × 874, 375 × 667, 874 × 402) и WebKit (402 × 874), доступность нижней кнопки, отсутствие горизонтального переполнения, полный маршрут, перетаскивание и клавиатура, все значения 1–5, возврат из сводки, сохранение ответов внутри макета и ветка ограничений. Первые восемь экранов при исходных ответах помещаются без прокрутки на основном размере. Длинные комментарии и раскрытые дополнительные сведения прокручиваются внутри, не перекрывая нижнюю кнопку.
