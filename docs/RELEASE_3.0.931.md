# Выпуск 3.0.931

Дата: 8 ноября 2026 года. Публикация: только Hosting проекта `tren-85720`.

## Изменения

- Черновик клиентского календаря содержит даты только невыполненных занятий. Номер связан с ID занятия, а не с позицией даты.
- Выполненные занятия отображаются по фактической дате и недоступны для изменения. Повторные номера из смеси истории и черновика устранены.
- Подсказка сообщает количество оставшихся дат и выполненных занятий. Пояснение о сохранности истории больше не порождает ложную красную ошибку; оформление результата сохранения задаётся явно.
- Сохранение выполняется транзакцией. Изменившееся с момента открытия расписание отклоняется без перезаписи; даты и метаданные выполненных занятий сохраняются.
- Восстановлен порядок 1–8 у указанного пользователем клиента. Изменены только `order`, `sortOrder` и позиции записей календаря: 8 записей, включая документ профиля. История и даты не менялись. Резервная копия metadata находится в игнорируемой папке `artifacts/calendar-order-repair/`; повторный dry-run требует 0 записей.
