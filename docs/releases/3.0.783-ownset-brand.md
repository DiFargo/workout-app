# OwnSet — версия 3.0.783

Выбран исходный логотип 05B: диагональная гантель с галочкой в рукояти.
Векторный мастер: [ownset.svg](../../public/brand/ownset.svg), белый знак на фоне `#3F73B8`.

## Что обновлено

- Название OwnSet и логотип на входе, React-загрузке, начальной HTML-загрузке и в брендинге админ-панели.
- Название вкладки, favicon, PWA manifest и Apple touch icon.
- Название Android-приложения, обычные, круглые и адаптивные launcher icons, splash-ресурсы.
- Версии package.json, package-lock.json и Android: 3.0.783.
- Генератор [generate-ownset-icons.mjs](../../scripts/generate-ownset-icons.mjs) создаёт PNG и Android vector drawable из единого SVG-мастера. Команда: `node scripts/generate-ownset-icons.mjs`.

## Проверка результата

- [x] Production build завершён, маркер dist содержит версию 3.0.783.
- [x] Оба мобильных сценария client-smoke прошли: проверка полей входа и проверка email для восстановления пароля. На Windows процесс runner не завершился после результатов тестов; это не считалось подтверждением завершения всего runner.
- [x] Визуально проверены вход и загрузка на ширине 402 px, админ-панель на 1366 px. Ширина/высота основного мобильного viewport 402 × 874 взяты из [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/layout). Это браузерная проверка, а не запуск на физическом iPhone.
- [x] Проверены загрузка SVG, название страницы, URLs и фактические PNG-размеры PWA-иконок, отсутствие горизонтального переполнения мобильного входа и загрузки.
- [x] Тесты форматирования версии: 2/2.
- [x] `cap sync android` завершён; Android-ресурсы скомпилированы локальным `aapt2 compile`.
- [x] Правки ограничены брендингом, ресурсами и номером версии; обработчики авторизации, Firebase, роли, маршруты и данные не удалялись.

Снимки и результаты: [папка проверки](../../artifacts/ownset-brand/), [checks.json](../../artifacts/ownset-brand/checks.json).

## Ограничения выпуска

Изменения подготовлены локально, публикация не выполнялась.
APK не собран: офлайн-сборке не хватает Android Gradle Plugin 8.13.0 и Google Services 4.4.4 в локальном кэше; сетевая загрузка недоступна в текущем окружении.
Обновление названия/иконки уже установленной PWA зависит от браузера; на iOS может потребоваться повторное добавление приложения на экран «Домой» после публикации.
