## Единый список приёмки

- [x] Подход и отдых не перекрываются при высоте Telegram-окна 250–300 px: правая колонка имеет естественную высоту, а не принудительно сжатую строку.
- [x] Квадратное видео использует высоту левой колонки; техника, заметка и дополнительные действия доступны в компактной вертикальной панели. Названия кнопок для средств доступности сохранены.
- [x] Главная, питание, прогресс и кабинет используют широкую горизонтальную компоновку. Портретный режим не меняется.
- [x] Шапки и нижнее меню компактнее; пять пунктов доступны, зоны нажатия не меньше 44 px. Прокрутка достигает последних действий над меню.
- [x] Разминка и таймер используют две колонки; заголовок разминки не забирает половину низкого экрана. Основные кнопки тренировки остаются не меньше 48 px.
- [x] Окна подготовки, завершения, продолжения/выхода, обратной связи и кабинета используют доступную ширину и ограниченную высоту с прокруткой. Календарь тренировок на широком низком экране отделяет сетку от сведений и управления.
- [x] Календарь питания: управление месяцем и переход на сегодня слева, прокручиваемая сетка дат справа; кнопки не обрезаются, минимальная ячейка 44 px по высоте.
- [x] Основной экран «Тренировки» также разделён на две колонки; компактная неделя, текущая тренировка и программа/история. Последние действия доступны прокруткой.
- [x] Сценарии проверены в светлой и тёмной темах, на коротких горизонтальных окнах; портретная матрица и WebKit с увеличенным текстом сохранены.
- [x] Данные, Firebase, аутентификация, роли, назначения, история и обработчики действий не меняются. Из JSX добавлены только группирующие div в питании; новых зависимостей нет.
- [x] Сборка, проверки артефакта и публикация Hosting завершены.

## Проверки и ограничения

Playwright: по 60 сочетаний экранов/диалогов, тем и размеров 874×300, 740×280, 568×250 в Chromium и мобильном WebKit. Ошибок JavaScript и горизонтального переполнения не обнаружено. При недостатке высоты содержимое доступно прокруткой — текст и цели нажатия не уменьшаются ради искусственного размещения всего сразу. Отдельно в обоих движках проверены сохранение значений при повороте 402×874 → 568×250 → 402×874 и доступность основной кнопки после прокрутки.

Четыре существующих E2E: портретная матрица, изменение размеров без потери значений, iPhone/Android с safe areas и увеличенным текстом, WebKit. После сокращения панели её кнопки возвращены к прежнему минимуму 48 px; соответствующая проверка повторно прошла.

Шесть сфокусированных проверок последовательного выполнения подходов и таймера, ESLint изменённого JSX, разбор CSS и `git diff --check` — успешно. Сборки staging/Production разделены, тестовый harness исключён. Бюджеты Production: начальный вход 72,04 / 100 КиБ gzip; обязательный запуск 528,48 / 640 КиБ; Firebase 162,65 / 170 КиБ.

Проверка на физическом телефоне внутри Telegram не выполнялась. Реальные аккаунты, дневники, тренировки и Telegram-сообщения не изменялись.
