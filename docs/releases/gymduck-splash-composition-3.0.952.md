# GymDuck — компактная заставка 3.0.952

## Изменение

Знак без надписи стал основным акцентом: до 160 px вместо 96 px. Название уменьшено до 32 px и средней насыщенности. Оставлены одна строка «Загружаем…» и короткий индикатор; повторяющиеся пояснения и дополнительные точки убраны из JSX.

Начальная HTML-заставка и React `AppSplash` используют одинаковую композицию чуть выше центра. На обычном экране прокрутка не нужна. При низком viewport знак уменьшается; при экстремально крупном тексте доступ к восстановлению сохраняется через прокрутку самой заставки, без глобального запрета прокрутки приложения.

## Критерии приёмки

- Знак, название и индикатор имеют одинаковые размеры и положение до/после старта React.
- Светлая и тёмная темы сохраняются с первого кадра.
- На 402×874, маленьком телефоне и landscape нет лишней прокрутки.
- Восстановление, offline-подсказка, кнопка повтора и reduced motion сохранены.
- Авторизация, роли, данные и дальнейшая загрузка приложения не меняются.

## Публикация

Только Firebase Hosting проекта `tren-85720`; Functions, правила доступа и пользовательские данные не изменяются. Сборка из отдельного архива целевого коммита исключает незавершённые сторонние правки.

Ранее одобренное превышение размера Firebase core остаётся прежним: 189,04 KiB gzip при лимите 170 KiB. Модуль должен совпадать с текущей Production-версией по SHA-256; лимит не изменяется.
