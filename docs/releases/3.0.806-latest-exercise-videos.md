Статус: опубликовано 19.09.2026 после явного подтверждения пользователя. Расширение нового приоритета на уже назначенные незавершённые тренировки не включено.

## Правило выбора

В пределах одного тренера и одного нормализованного упражнения с одинаковой техникой список отдаёт приоритет последнему сохранённому видео. Используется `videoUpdatedAt`; для старых общих карточек без этого поля — `updatedAt`/`createdAt`. Дата правки всей программы не является датой видео.

Сервер карточек сохраняет `videoUpdatedAt` при создании/замене видео. Изменение названия, описания, кадрирования, удаление и восстановление не обновляют дату ролика. Известная дата видео из старой записи сохраняется при переносе в общую карточку. Для старых карточек точная историческая дата загрузки неизвестна: дата карточки остаётся резервным ориентиром до первой замены видео.

Если даты отсутствуют или несколько разных роликов имеют одинаковую последнюю дату, алгоритм не угадывает победителя. Разные владельцы, техники, положения тела, хваты и оборудование не объединяются только из-за похожих названий. Сохранённые legacy-идентификаторы позволяют скрывать старые копии после переименования общей карточки.

Удалённый ролик не выбирается основным; удаление одного варианта не скрывает другой активный вариант и не убирает возможность восстановления. Документы не удаляются, программы и история не переписываются. Текущий механизм обновления связанных карточек в назначенных тренировках не изменялся; новый приоритет между разными роликами реализован для библиотеки и выбора упражнений из неё.
