## Реализация и проверка

Размер принадлежит CSS Module `ClientPageHeader`: введён локальный токен `--client-primary-title-size`, который читает существующее приоритетное правило Apple-темы. Сокращены только высота строки и нижний отступ основной шапки в активном клиентском оформлении. Шрифт задан в `rem`; строка растёт при увеличении текста. Старые точные ожидания 32 px в четырёх существующих UI-проверках обновлены до текущего размера.

`ui-ux-pro-max` использован для сохранения иерархии заголовков, safe-area и полноразмерных областей нажатия при уплотнении интерфейса.

Пройдены две существующие проверки размера заголовков (мобильная и настольная). Дополнительно проверены 30 комбинаций реального клиентского интерфейса: пять экранов × две темы × 402×874, 320×720, 874×402; ещё 10 сценариев с текстом 160% и 10 с имитацией верхнего safe-area 59 px. Проверены геометрия, совпадение высоты шапки с резервом, отсутствие горизонтального переполнения, кнопки и неподвижность шапки после прокрутки. Ошибок JavaScript нет.

Проверки проводились локально на изолированных данных. Незавершённые сторонние изменения приглашений тренера не входят в пакет.
