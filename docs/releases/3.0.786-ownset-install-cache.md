# OwnSet 3.0.786 — обновление кешированных данных бренда

Существующий service worker читает изображения и манифест сначала из кеша. Замена содержимого по прежнему URL оставляла старый значок и название Workout App в ранее открытых клиентах.

Добавлена версия `?v=gradient-1` к адресам SVG на начальной загрузке, React splash, входе и в админке, а также к favicon, Apple icon, манифесту и его PWA-иконкам. Алгоритм кеширования, геометрия и бизнес-логика не менялись.

Production build, Capacitor sync и проверка diff прошли. В Chromium с работающим service worker заранее сохранены старый синий SVG и манифест Workout App. Проверка подтвердила: старый URL продолжает возвращать кешированную картинку, новый адрес получает градиент; `Page.getAppManifest` возвращает OwnSet и новые адреса иконок. Это проверяет сценарий обновления, а не только чистую установку.

Системный экран запуска уже установленного PWA обновляется самим браузером/ОС; тест не подтверждает обновление ярлыка на физическом телефоне пользователя.
