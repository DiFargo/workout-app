# Выпуск 3.0.949 — выбор «Без программы»

## Изменения

- В выборе программы клиента первый доступный вариант — «Без программы», с отдельной кнопкой «Сохранить» и подтверждением.
- Сохранение переносит все ещё не архивированные назначения тренера в архив. Старые копии и очередь не становятся активными вместо снятой программы.
- Тренировки не удаляются. Выполненные подходы, история, абонемент и базовые планы сохраняются. Из активного календаря убираются только даты снятых назначений; резервные даты остаются в архиве.
- Проверка свежих данных и транзакция останавливают сохранение при одновременном изменении программы, календаря или тренировки. Действие доступно только при сохранении текущей сессии и прав на клиента.
- Обычное назначение, отдельное архивирование и возврат программы остаются доступны. Кнопка подтверждения «Без программы» использует фирменный зелёно-синий градиент.

## Проверки

- Целевые тесты обработчиков, принадлежности назначения и сохранности данных; ESLint изменённых файлов; `git diff --check`.
- Правила Firestore в эмуляторе: архивирование последнего назначения, ограниченная резервная копия календаря, запрет изменения чужих данных и сохранность завершённых тренировок.
- Сфокусированная проверка интерфейса на телефоне и ПК: выбор, отмена, сохранение, ошибка с повтором и архив.
- Свежая Production-сборка и проверка артефакта `tren-85720`. Публикация только Hosting, без изменения правил, функций или прав доступа.
- Живая проверка выявила ложный конфликт при различном порядке ключей объектов Firestore. Тестовые данные полностью очищены. Исправление сравнения и итоговая проверка входят в 3.0.950.

Известное ограничение: ранее согласованный Firebase core превышает бюджет 170 KiB gzip. Перед публикацией проверяется его побайтное совпадение с предыдущей Production-версией; сам лимит не меняется.
