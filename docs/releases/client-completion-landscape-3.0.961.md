# 3.0.961 — завершённая тренировка на главной и горизонтальный экран

База: опубликованная 3.0.960, контрольная точка `3742a00f`.

## Изменения и критерии приёмки

- [x] Если сегодня есть подтверждённая сохранённая тренировка и нет актуальных задач, карточка на главной показывает «Отличная работа!» и подтверждение сохранения вместо совета об отдыхе. Похвала отмечает участие, а не приписывает рекорды или выполнение всех подходов.
- [x] Используется фактическая локальная дата сессии. Черновики, ожидающие синхронизации, отменённые записи, даты импорта и ручная отметка плана не считаются подтверждённой тренировкой за сегодня.
- [x] Незавершённая тренировка, задания тренера и проверка неизвестных данных сохраняют приоритет. Переход к следующей тренировке остаётся доступен.
- [x] На невысоком горизонтальном экране видео находится слева, выбранный подход, отдых и основное действие — справа. Портретная компоновка сохранена.
- [x] Списки подходов раскрываются вниз и остаются доступны; поворот не сбрасывает значения. Крупный шрифт допускает прокрутку с сохранением безопасного нижнего отступа.
- [x] Существующие обработчики выполнения, переходов, отдыха и сохранения не заменялись. Firebase, роли, назначения программ и пользовательские данные не изменялись; новых запросов и зависимостей нет.

## Проверки

- 21 сфокусированная автоматическая проверка: модель главной, React-отображение, приоритет задач, основной сценарий подходов и таймер.
- 4 существующие E2E-проверки: портретная матрица размеров, изменение размеров без потери значений, iPhone/Android с safe areas и увеличенным текстом, WebKit с увеличенным текстом.
- Playwright CLI: обе темы, 874×402, 740×360, 568×320 и 402×874; отдельно горизонтальные отступы 47/47/21 px, меню подходов/выполнения, открытие отдыха после выполнения и возврат к следующему подходу. На обычном шрифте видео, подход и кнопка доступны одновременно; горизонтального переполнения и ошибок JavaScript не обнаружено. На увеличенном шрифте проверена доступность кнопки прокруткой.
- Новая похвала просмотрена в обеих темах на изолированных UI-данных. Тестовый harness исключается из Production.
- ESLint затронутых JS/JSX и тестов, разбор четырёх CSS-модулей, `git diff --check` — без ошибок.

Проверки не заменяют проверку поворота на физическом устройстве в Telegram. Реальные тренировки и аккаунты при проверке не менялись.
