# 3.0.802 — единые стили окон кабинета

## Изменения

- Фото прогресса, замеры и настройки аккаунта используют актуальные цвета, типографику, карточки и действия OwnSet.
- Сохранены загрузка и сравнение фото, 12 замеров, редактирование имени и логина, смена пароля и закрытие окон.
- Зоны нажатия маленьких кнопок увеличены до 44 px. На узком экране данные не перекрывают действия.
- По ui-ux-pro-max использованы единые состояния, семантические цвета и мобильные размеры элементов без изменений бизнес-логики.

## Проверка

- `npm run verify`: production build, бюджет начальной загрузки, whitespace.
- `tests/e2e/profile-sheet-styles.spec.js`: 6 сценариев, 402×874 и 320×568; сравнение фото, 12 значений замеров, редактирование аккаунта, закрытие и доступность действий.
- Визуально проверены скриншоты трёх окон. Тестовые данные замеров исправлены, чтобы единицы измерения не дублировались.
- Область релиза: Firebase Hosting; данные пользователей, Functions и Rules не меняются.

Опубликовано 19.09.2026. Production smoke: HTTP 200, 18 файлов совпали с проверенной сборкой, мобильный запуск 402×874 без JS-ошибок и горизонтального переполнения. Анонимные обращения к двум защищённым API отклонены с 401; записей данных пользователей не было.
