# Локальная админка с актуальным интерфейсом · 3.0.966

## Результат

Команда `npm run dev:admin` открывает `http://127.0.0.1:4175/` без настройки Firebase. Используются настоящие `AdminPanelHub`, `AdminUsersWorkspaceRoute`, `AdminTrainerProfileRoute` и `AdminLibraryRoute`, их текущие CSS Modules и системные программы. Старые тёмные демонстрационные экраны `adminHarness` больше не рекомендуются для разработки интерфейса.

Пользователи синтетические. Программы и переопределения упражнений сохраняются в памяти локального сервера, переживают перезагрузку страницы и сбрасываются при перезапуске сервера. Поиск, просмотр состава, создание черновика и навигация работают в реальных компонентах. Для недоступных разделов показывается объяснение; профиль тренера остаётся открыт, модальные действия не перекрываются служебным уведомлением.

## Изоляция

- Отдельные DEV-вход и Vite-конфигурация; сборка этим конфигом запрещена.
- `.env` не читаются. Firebase SDK, API, Storage и защищённое видео заменяются только в этом входе. Сервер слушает loopback; внешние подключения блокирует CSP.
- Firestore-подобный транспорт допускает только локальные каталоги программ/упражнений и версии программ. Неизвестные API и Telegram-операции отклоняются.
- Настоящие вход, личные данные, медиа и серверные интеграции требуют отдельного согласованного staging-окружения. Локальные приглашения не создают ссылок активации.
- Production-код, роли, Rules, авторизация, тренировки, питание, замеры и существующие E2E-harness не изменены.
