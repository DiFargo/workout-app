# 3.0.959 — компактный обзор тренера по утверждённому макету

Дата: 13 ноября 2026 года. База: опубликованная 3.0.958 (`5202e07f`).
Пользователь утвердил макет, перенос в приложение и публикацию после проверки.

## Изменения и критерии приёмки

- На компьютере приоритетная задача и события расположены рядом. Карточка задачи имеет естественную высоту, без растягивания до нижней границы соседних разделов.
- «Мои клиенты» — отдельный блок ниже на всю ширину, с двухколоночной сеткой. На телефоне порядок: задача → события → клиенты.
- Клиенты из очереди остаются в ростере. Сохранено исключение архивных и тестовых аккаунтов. Предпросмотр ограничен четырьмя клиентами; общий счётчик и переход «Все клиенты» показывают полный доступный каталог.
- Из ростера убрана строка «Шаблоны программ». Раздел «Программы» в нижней навигации сохранён.
- Основная кнопка содержит имя клиента. Статус настройки показывается только для реального setup-сигнала; другие сигналы не подменяются.
- Очередь, раскрытие дополнительных задач, фильтры журнала, отметки просмотра и существующие назначения переходов сохранены. Открытие задачи не снимает её с очереди.
- Сохранены действующие градиенты двух тем и нижняя стеклянная навигация. Новые запросы данных и зависимости не добавлялись.

## Выполненные проверки

- 18 сфокусированных проверок: `trainer-daily-journal.test.mjs`, `remediation-trainer-ux.test.mjs`, новый тест реальной SSR-отрисовки `trainer-overview-roster-react.test.mjs`.
- ESLint изменённого компонента и тестов; `git diff --check`.
- Chromium: светлая и тёмная темы на 1366×950, 402×874, 320×720 и 874×402. Проверены порядок секций, геометрия desktop-сетки, отсутствие горизонтального переполнения, размеры клиентских кнопок и контраст текста ростера ≥4,5:1.
- Вручную просмотрены desktop/phone-скриншоты обеих тем. После завершения анимации подсветка нижней навигации совпадает с выбранной кнопкой.
- На изолированных данных проверены: основная задача открывает нужного клиента и не исчезает после просмотра; событие по Enter открывает питание нужного клиента; строка ростера открывает сводку; «Все клиенты» открывает каталог без подмены идентичностей.
- Новых ошибок JavaScript в этих сценариях не обнаружено. Внешние Telegram/Google-транспорты локального тестового проекта изолированы; реальная авторизация при этих UI-проверках не использовалась.
- Staging- и отдельная свежая Production-сборка прошли. Production-бюджеты gzip: начальная статика 72,04 / 100 KiB; обязательная загрузка 528,31 / 640 KiB; Firebase 162,65 / 170 KiB. E2E-harness в Production-артефакте отсутствует.
