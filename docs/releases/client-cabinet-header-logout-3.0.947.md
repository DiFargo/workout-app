# 3.0.947 — выход в шапке клиентского кабинета

## Изменения

- Вместо дублирующего значка оформления в шапке — выход из аккаунта.
- Выход требует отдельного подтверждения; «Остаться», Escape и закрытие по фону не завершают сеанс.
- Во время операции повторный вызов заблокирован. После отмены или неудачного выхода кнопка снова доступна, фокус возвращается к ней.
- Нижняя дублирующая кнопка выхода убрана только у клиента. Пункт «Оформление» в настройках сохранён.
- Обновление данных и нижний выход в staff-кабинете не менялись. Используется существующий обработчик Firebase sign-out, без изменений прав, данных и черновиков.

## Проверка перед публикацией

- ESLint изменённых JSX и тестов; `git diff --check`.
- 3 поведенческие React-проверки: реальное подтверждение, отмена/клавиатура/фокус, однократный callback и повтор после `false`, сохранение оформления и staff-ветки.
- 12 существующих проверок logout/bootstrap, включая сбой Firebase и конкурирующий вход.
- 2 целевых E2E: доступность выхода в закреплённой шапке и смена тем через оставшийся пункт настроек.
- 6 визуальных сочетаний: светлая/тёмная тема, 320×640, 402×874 и 1366×768. Кнопка 44×44, без перекрытия заголовка и горизонтального переполнения; подтверждение помещается в экран.

Проверки интерфейса выполнялись на локальных фикстурах без реальных аккаунтов и внешних записей. Полный набор Rules/Functions не запускался: они в этом пакете не меняются. Публикация ограничена Firebase Hosting проекта `tren-85720`, из чистого архива целевого коммита. После публикации проверяются совпадение публичных файлов с артефактом и загрузка экрана входа без выхода из аккаунта пользователя.
