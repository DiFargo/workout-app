# Выпуск 3.0.948 — клиент без назначенной программы

## Изменения

- В пустом состоянии индивидуальных тренировок убраны упоминание базового режима и кнопка «Открыть кабинет». Нижняя навигация сохранена.
- Мобильная оболочка главной и кабинета ограничена меньшей из доступной высоты Telegram и текущего CSS viewport. Общий адаптивный стиль больше не заставляет короткую главную использовать недоступную часть экрана.
- Нижний отступ для плавающего меню, закреплённая шапка и сохранение позиции прокрутки оставлены без изменений. Firebase, роли, программы и история не меняются.

## Проверки

- ESLint изменённого JSX и двух целевых E2E-файлов; `git diff --check`.
- Chromium и WebKit: пустой индивидуальный план без лишних действий; переход в кабинет через нижнее меню.
- Chromium и WebKit: короткая главная с одной задачей «Ожидаем программу тренера», доступная область Telegram 620 px при CSS viewport 874 px, safe area 34 px; светлая/тёмная темы; карточка тренера достигается прокруткой, шапка не смещается.
- Уменьшение текущего viewport до 560 px не растягивает оболочку по прежней стабильной высоте Telegram. Проверен и кабинет.
- Chromium: существующая регрессия пяти вкладок, закреплённой шапки и тёмной анкеты.
- Свежая Production-сборка и проверка артефакта для `tren-85720`; публикация только Hosting.

Физический iPhone 17 Pro с Telegram недоступен автоматическим проверкам. После обновления требуется подтвердить свайп именно на устройстве пользователя.

Известное ограничение сборки: ранее согласованный Firebase core остаётся выше бюджета 170 KiB gzip. Его содержимое необходимо сверить с опубликованной базой; лимит не изменяется. Полный набор проверок правил/API не повторяется для этого локального UI-исправления.
