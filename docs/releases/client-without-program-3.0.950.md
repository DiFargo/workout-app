# Выпуск 3.0.950 — безопасное сохранение «Без программы»

Продолжение 3.0.949: в выборе программы клиента доступен первый вариант «Без программы» и действие «Сохранить». Назначения перемещаются в архив без удаления выполненных тренировок, подходов, истории или изменения абонемента.

## Исправление живой проверки

Firestore может возвращать одинаковые поля объектов в разном порядке. Сравнение через `JSON.stringify` ошибочно считало такие документы изменёнными. Теперь используется уже существующий канонический снимок `programDraftSnapshot`, независимый от порядка ключей. Настоящие изменения по-прежнему останавливают транзакцию.

Базовые копии исключены из выбора активного назначения тренера. Они не изменяются и не считаются возвращённой старой индивидуальной программой.

## Проверки

- 63 целевых теста: снятие программы с историей, сохранность данных, очередь, календарь, чужой клиент, смена сессии, реальные конфликты и перестановка ключей без изменений.
- Четыре проверки правил Firestore в эмуляторе; права доступа не изменены.
- Шесть проверок интерфейса телефона и ПК: выбор, отмена, ошибка и повтор, архив и обычное назначение; мобильный вид подтверждения проверен по скриншоту.
- Настоящий SDK и временный тренер в Production: все тестовые назначения сняты, история/подходы/абонемент сохранены, после повторного чтения старая очередь не активируется. Временные аккаунты и данные полностью удаляются с проверкой отсутствия.
- Production-сборка из отдельного чистого снимка Git, проверка артефакта и SHA-256 опубликованных файлов. Публикация только Hosting.

Firebase core побайтно совпадает с ранее опубликованной версией; ранее согласованное превышение бюджета размера не увеличено, лимит проверки не изменён.
