# OwnSet 3.0.788 — устранение голубой вспышки при касании

В мобильном Chromium подтверждена стандартная подсветка `rgba(51, 181, 229, 0.4)` на элементах входа, пяти клиентских страниц, упражнения и редактора подходов. Локальные правила покрывали только часть интерфейса.

Для `html` задано наследуемое `-webkit-tap-highlight-color: transparent` в базовом reset и в начальном HTML до загрузки CSS. Собственные состояния нажатия, keyboard focus, выделение текста и обработчики не менялись.

Проверка с реальными touch-нажатиями в Chromium на 402×874: на всех 550 проверенных элементах восьми поверхностей подсветка прозрачна; переходы по пяти вкладкам и открытие редактора подхода работают. Клавиатурный `:focus-visible` и ввод текста проверены. Production build, Capacitor sync и diff check прошли.

Артефакты: `artifacts/tap-highlight/before.json`, `artifacts/tap-highlight/after.json`, `artifacts/check-tap-highlight.mjs`.
