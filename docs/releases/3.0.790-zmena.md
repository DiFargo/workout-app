# Zmena 3.0.790 — новое название

По выбору пользователя Formora переименован в Zmena: вкладка браузера, метаданные установки, начальная загрузка, React splash, вход, бренд администратора, SVG title, отображаемое название Capacitor/Android.

Градиентный значок и его геометрия, имена файлов, идентификатор приложения, стили и бизнес-логика сохранены. Манифест использует `?v=zmena-1` для обхода ранее сохранённого названия. Юридическая доступность названия не подтверждена; переименование выполнено по явному запросу пользователя.
