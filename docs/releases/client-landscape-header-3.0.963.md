# 3.0.963 — компактное угловое действие в горизонтальном режиме

Статус: подготовлено и проверено локально, **не опубликовано**. База — опубликованная 3.0.962, `0ee21af5`.

## Единый список приёмки

- [x] На пяти главных клиентских вкладках в landscape при высоте до 500 px заголовок не занимает отдельную строку. Резерв шапки — 0 px вместо 50 px; `h1` остаётся доступным экранному диктору.
- [x] Функциональное действие остаётся в правом верхнем углу с зоной нажатия 48×48 px. Узкая боковая зона защищает содержимое от наложения кнопки.
- [x] Положение кнопки учитывает CSS safe area и Telegram content/safe-area отступы. На экране без действия боковой резерв не добавляется.
- [x] Портретная компоновка и обычное окно компьютера не меняются. После поворота шапка восстанавливается.
- [x] Заголовки диалогов не скрываются. Уведомления, расписание тренировок, календарь питания, замеры и подтверждение выхода открываются прежними кнопками.
- [x] Firebase, аутентификация, роли, данные, навигация, обработчики и нижнее меню не менялись. Runtime-diff — два CSS Modules; версия 3.0.963 подготовлена в корневых package-файлах.
- [x] Сборка, проверка бюджета и `git diff --check` прошли.

## Проверки

По 60 сочетаний в Chromium и мобильном WebKit: пять вкладок × две темы × три коротких горизонтальных размера (874×300, 740×280, 568×250) и три контрольных вертикальных/настольных размера (402×874, 375×812, 1366×768). В landscape резерв шапки равен нулю, кнопки доступны и не пересекаются с другими интерактивными элементами; горизонтального переполнения и ошибок JavaScript нет. В портрете резерв 56 px и видимые заголовки восстановлены.

Пять угловых действий отдельно проверены в Chromium без сохранения данных и без подтверждения выхода. В мобильном WebKit дополнительно проверены текст 20 px, reduced motion, верхний Telegram content inset 12 px и правый 24 px: кнопки полностью доступны.

Production-сборка повторно выполнена на Node 22, бюджет: начальный вход 72,04 / 100 КиБ gzip, обязательный запуск 525,59 / 640 КиБ, Firebase 159,69 / 170 КиБ. E2E-harness отсутствует в артефакте. Существующее предупреждение Vite о крупных chunks не является ошибкой сборки.

UI-навык `ui-ux-pro-max` использован для сохранения safe areas, доступного названия раздела и размера нажатия; подходящей React-рекомендации в локальной поисковой базе не найдено. Проверка геометрии выполнена на реальном DOM.

Нативная строка Telegram `GymDuck` не менялась. Её нельзя скрыть CSS; отдельный `requestFullscreen()` (Bot API 8.0+) требует проверки на физических Android/iOS Telegram и не включён в эту точечную правку. Физический телефон не проверялся. Публикация требует отдельного запроса пользователя.
