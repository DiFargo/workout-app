# Formora 3.0.789 — новое название

По выбору пользователя OwnSet переименован в Formora. Обновлены название вкладки и метаданные Apple/PWA, окно установки, начальная загрузка, React splash, вход, бренд администратора, SVG title и отображаемые названия Capacitor/Android.

Выбранный градиентный значок, его геометрия, имена файлов, идентификатор приложения и бизнес-логика сохранены. URL манифеста получил `?v=formora-1`, чтобы существующий service worker не возвращал старое название.

Production build и Capacitor sync прошли. На 402×874 проверены заголовок Formora, загрузка логотипа, отсутствие переполнения, оба splash, логотип администратора и размеры/доступность PWA PNG. Проверка diff прошла. APK не собирался; уже установленный ярлык обновляется браузером/ОС отдельно.
