# Проверяемый каталог продуктов

Каталог загружается лениво и состоит из двух самостоятельных слоёв:

- `public/nutrition-catalog/sku/` — реальные товарные позиции с валидным GTIN,
  точным названием из исходной записи и КБЖУ на 100 г;
- `public/nutrition-catalog/reference/` — обычные продукты без бренда (например,
  бананы и яблоки) из официального справочника состава продуктов.

Фото не является условием включения. Для каждой записи обязательны полный набор
КБЖУ на 100 г, ссылка на первоисточник, дата получения и URL доказательства.
Значения не вычисляются и не дополняются приложением.

## Русский поиск

Поиск принимает русский запрос как основной. Модуль
`russianSearchLexicon.js` раскрывает только пищевые термины запроса
(например, `говядина` → `beef`) и ранжирует прямое русское совпадение выше
раскрытого. Он не переводит и не заменяет исходное имя, бренд, GTIN или КБЖУ
в записи. Английское название и название бренда остаются рабочим резервным
вариантом поиска.

Каждый слой содержит одинаковый набор runtime-файлов:

- `foods.compact.json` — данные для поиска;
- `alias-exact-index.json`, `alias-prefix-index.json`, `search-token-index.json` — индексы;
- `barcode-index.json` — поиск SKU по GTIN;
- `foods.full.json`, `provenance.json`, `catalog.meta.json` — полная проверяемая версия и метаданные.

Полное происхождение данных, лицензии и команды повторной сборки описаны в
[`docs/nutrition-catalog-sources.md`](../../../docs/nutrition-catalog-sources.md).
